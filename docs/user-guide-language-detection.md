# 语言检测功能使用指南

## 功能说明

LingoPDF 现在支持在上传文件后自动检测文件的实际语言，并在文件列表中显示检测到的源语言标识。

## 使用方法

1. 上传 PDF 文件（拖拽或选择）
2. 系统会自动检测文件的语言
3. 语言标识显示在每个文件旁边：
   - 🇬🇧 English（英语）
   - 🇨🇳 Chinese（中文）
   - 🇯🇵 Japanese（日语）  
   - 🇰🇷 Korean（韩语）
   - 🇷🇺 Russian（俄语）

## 语言不一致提示

- 如果检测到的语言与选择的目标语言一致（如中文 PDF 被翻译为中文），会显示提醒标签
- 建议根据实际需要调整翻译方向，避免重复翻译

## 支持的语言

| 语言代码 | 显示名称 | 国旗标识 |
|---------|---------|----------|
| en | English | 🇬🇧 |
| zh | Chinese | 🇨🇳 |
| ja | Japanese | 🇯🇵 |
| ko | Korean | 🇰🇷 |
| ru | Russian | 🇷🇺 |

## 技术实现

- 使用 pyPdf 库进行 OCR 语言检测
- 检测过程在服务器端通过 AI 分析 OCR 后的文本内容
- 检测结果显示为带颜色编码的旗帜标签
